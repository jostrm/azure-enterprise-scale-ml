    Every variable in variables.json¶

    variables.json holds the settings of an AI Factory project and its scale set. This page lists all 419 variables of the shared template (section dev), with the default value and what each one does.

    Change a variable through a tool, not by hand: see change a setting. For the matching Azure DevOps and GitHub names, see the complete reference.

    Required says whether you must set the variable: Yes, No, or Depends when another choice decides it. A default in quotes is text: "true" and "false" are written as text in this file.

    The project pipelines read variables.json. The separate AI gateway pipeline does not: it reads the apimGateway… and kongGateway… settings from variables.yaml (Azure DevOps) or the GitHub variables.
