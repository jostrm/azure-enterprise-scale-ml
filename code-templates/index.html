    Before you run a template¶

    1. Ask your platform team for a project: see Usage docs and the prerequisites.
    2. Check that the project has the services on the card. The Azure resource library names the setting that switches each one on.
    3. Open the template and follow its guide. New to the Agent Factory or the Model Factory? Start with Run your first agent or Train your first model.

    Where the templates live¶

    Folder in usecase_code What it holds
    40-agent-factory The Agent Factory: prompt agents, hosted agents, RAG, voice, MCP and the agents that work with Fabric and Azure Machine Learning.
    50-ml-model-factory The Model Factory: batch, online and streaming examples for each task and technology. The library lists the examples that are tested in Azure. The use-case tree has all of them.
    10-azure-function Azure Functions, including the one that runs the six ESAF scenarios.
    20-agent-foundry Two starter scripts for Foundry agents, each in one file.
