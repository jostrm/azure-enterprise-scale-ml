LOCAL INVITATION PREVIEW (development-only):
The local-invitation-gate/nonconfidential-guides mode needs no server. Enter the
owner-provided invitation at "Preview Code To Enter" for the current session.
Tutorial guides and a salted verifier are bundled and can be extracted. This is
a convenience gate for trusted users, NOT confidentiality or server licensing;
it has no remote revocation or expiry. Never put the actual code in support logs.
Recordings are unavailable; missing scenarios are not a completed video rollout.

PROTECTED SERVICE MODE:
Protected catalog, tutorial documents and media require the approved online
service and a valid entitlement. Nothing is licensed for offline caching.
Enter an approved code at "Preview Code To Enter". Server-side code validation
unlocks all enabled tutorials; the development-only .invalid endpoint cannot.
Public endpoint configuration uses PreviewApiBaseUri in previewsettings.json or
ESAIF_PREVIEW_API_URL. Neither location is a place for a secret or preview code.
Session expiry and server restart require reauthentication. Preview cannot
prevent authorized viewers recording the screen or retaining received bytes.
In either mode, do not send invitation codes, license keys, session tokens or
media links in support requests.

Unsigned installers marked development-only are local test artifacts, not
production releases. Do not bypass Windows organizational security policies.
Production requires verified publisher signing and trusted timestamping.

Upgrade: close the app and run the newer installer under the same Windows user.
The installer does not stop applications automatically or by process name.
Downgrade: only after support confirms state-format compatibility, run the
selected older version with /ALLOWDOWNGRADE=1. Never choose a different app's
installation directory. Uninstall/reinstall is the explicit clean-binary
rollback option and retains TutorialApp settings/progress.

Settings/progress under %LOCALAPPDATA%\ESAIF.TutorialApp are retained during
upgrade and uninstall. No unrelated application data is removed. Deleting
personal state is a separate, deliberate user action; no automatic deletion
script is provided.
