Enterprise Scale AI Factory - Windows desktop edition

Supported target: Windows 11 x64, build 22000 or newer.
Verified build platform: Windows 11 x64 build 26100.
ARM64 and Windows Server are not supported by this installer.

The application includes its .NET 10 runtime, Windows App SDK runtime and
frozen Python API. No .NET SDK, .NET runtime or Python installation is needed
to open the desktop application or use its bundled local API.

Microsoft Edge WebView2 Evergreen Runtime is a separate prerequisite.
Setup checks for it and stops with installation guidance when it is missing.
Get it from https://developer.microsoft.com/microsoft-edge/webview2/
Windows 11 normally includes WebView2; managed/offline images may not.

Azure deployment actions are separate from application startup: they require
the relevant Git for Windows/Git Bash, Azure CLI, GitHub CLI and Python 3
tools, appropriate credentials, permissions and network connectivity.
Installing this application does not log in to Azure or deploy resources.

An explicit local accelerator snapshot includes current bootstrap/template
files rather than silently downloading stale remote main. Backend deployment
provenance checks still require compatible published release/main commits
and a Git repository containing those objects. A source-only snapshot without
.git is sufficient for app startup/schema/templates, NOT for deployment
source verification. Packaging does not bypass that fail-closed protection.
See BUILD-INFO.json for this bundle's source inventory and Git metadata flag.

Setup installs per-user without administrator privileges. Uninstall from
Windows Settings > Apps. User configuration/history under LocalAppData is
retained when uninstalling. Setup does not delete unrelated files.

Keep setup.exe and ALL matching setup-*.bin slices in the SAME directory.
Each slice is below the GitHub 100 MiB per-file limit.
Verify their SHA-256 hashes against SHA256SUMS.txt before installation.

This build is unsigned. Windows SmartScreen may show an unknown-publisher
warning. Production distribution should Authenticode-sign the application
and setup with the publisher's certificate and trusted timestamp.

Third-party component license texts and dependency inventory are included
in the Licenses directory. Inno Setup is used under its 6.4.3 license.
