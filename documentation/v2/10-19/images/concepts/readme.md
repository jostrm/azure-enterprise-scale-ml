# Concept animations

`mlops.gif` and `dataops-rag.gif` are the MLOps and DataOps + RAG lessons of the AI Factory Config Wizard's
concept animations (illustrative, not live state), exported at 3x with its offline exporter
(`ESAIF.ConfigWizard/tools/ConceptAnimationExport`, jostrm/maui-apps `7c78bb6`). To refresh them, run
`Export-ConceptAnimations.ps1` there and copy the two GIFs here.
