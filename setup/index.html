    Setup docs: set up your AI Factory¶

    Go from an empty Azure subscription to a working AI Factory with its first project and its first agent. These pages are for the platform team (the core team) that creates and runs the Factory.

    Many tools, one goal¶

    Every tool is an L1 client of the same Factory API, so the result is the same whichever you pick. The app, the azurefactory CLI (in PowerShell or Bash), the Python SDK and REST all send the same six scenario calls. See the onion architecture for the layers below your tool.

    Set up¶

    Quickstart What you do
    Install the ESAF tools Install a tool, start the Factory API and check the connection.
    Create your AI Factory Create the Factory and its first project with one call. Scenario 1.
    Add a scale set Add a second network for more projects. Scenario 2, optional.
    Add a project for your team Add or update a project with one call. Scenario 3.

    Build your first agent¶

    Quickstart What you do
    Create your first agent by enabling ESAF Agent Chat Switch on a chat agent that answers questions about your Factory.
    Run your first agent in your ESAF project Hand over to the project team to plan and deploy their own agent.

    Train a model¶

    Quickstart What you do
    Train your first model in your ESAF project Hand over to the project team to validate a scenario and train a model.

    Clean up¶

    Quickstart What you do
    Clean up Delete a project, a scale set or the whole Factory. Scenarios 4 to 6.

    Run it guided¶

    The ESAF Tutorial Guide is a Windows app (installed as ESAF Tutorials) that runs the same quickstarts with you. It types each command, checks every step and plays a video of each scenario. Pick the tutorial for your tool (CLI, Python SDK or REST), then the track Scenarios 1-3 to build or Scenarios 4-6 to clean up. It runs on Windows. On Linux and macOS, follow the quickstarts with the CLI (bash), Python SDK or REST tab. Download the ESAF Tutorial Guide. It's a private preview: ask Joakim Åström on LinkedIn for a preview code.

    Try it first (preview)¶

    Option What you do
    Deploy to Azure (preview) Deploy a test Factory with project 001 from the Azure portal. It's a quick test, not a governed Factory.

    Run it yourself or from your service desk¶

    You can run the scenarios yourself, or let teams order projects from ServiceNow, Jira Service Management or your own portal. Your automation then calls the same Factory API. See ITSM integration.
