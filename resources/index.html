    Azure resource library¶

    This library lists 54 Azure resources of an AI Factory. 50 of them have a setting that switches them on, for a project or for the common part. The others are always there, or are an integration. Each card names the setting, links to its explanation and says whether it is on by default.

    Type in the search box, or tick the boxes. Ticks in one row widen the choice, and rows narrow each other. Full stack has what an application needs around its AI: the front end, databases, a cache, Container Apps, AKS and API Management.

    Always there¶

    Every project also gets a storage account, managed identities and its own subnets. The common part of a scale set has the network, the data lake, a container registry and Log Analytics. They have no switch.

    Switch a resource on or off¶

    Change the setting with a tool: see Add and update, or pass settings to esaf.upsert_project(...) as in Enable ESAF Agent Chat. Every setting is explained in Every variable in variables.json.

    Before you switch a resource off, read what happens when you switch a service off.

    Looking for code that uses a resource? Open the code templates library, or select the link on a card. The architecture images use the same names.
